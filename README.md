# TestAnchor 핀 리뷰 보드

동욱 님을 위한 **화면 시안 + 서버 흐름도 통합 핀 리뷰 보드**입니다.
웹에서 시안과 흐름도를 보고, 의견을 남길 자리를 톡 누른 뒤 한 줄만 적으면 됩니다.

- 앱: `index.html` · `styles.css` · `app.js` (빌드 없음, 정적 파일)
- 로그인 없음. 아이폰 Safari 와 PC 브라우저에서 바로 열립니다.

## 쓰는 법

1. 위쪽 탭에서 **① 화면 시안** 또는 **② 서버 흐름도**를 고릅니다.
2. `📌 핀 찍기` 모드로 바꾸고, 의견을 남길 자리를 **짧게 탭**합니다.
3. 뜨는 시트에 한 줄 적고 **저장**. (빠른 문구 버튼을 눌러도 됩니다.)
4. 오른쪽 아래 **의견 제출**을 누르면 피클에게 전달됩니다.
5. `📌 남긴 의견` 목록에서 핀을 누르면 그 자리로 이동합니다.

흐름도 탭은 `+ / − / ⤢` 버튼, 두 손가락 확대, 끌어서 이동을 지원합니다.

## 의견은 어디로 가나

- 제출하면 `ntfy.sh` 채널 `pk-ta-rb-9f24c1d7a3be5e60` 로 JSON 이 POST 됩니다.
  (로그인·키가 필요 없는 전송 채널입니다.)
- 피클은 같은 채널을 읽어 의견을 확인합니다.

```bash
# 최근 12시간 동안 도착한 제출 (줄마다 JSON)
curl -s 'https://ntfy.sh/pk-ta-rb-9f24c1d7a3be5e60/json?poll=1&since=12h'
```

## 데이터 보관

- 브라우저에는 `localStorage` 로 남습니다(같은 기기에서 다시 열면 그대로).
- 전송 채널(ntfy.sh)은 메시지를 **12시간**만 보관합니다. 그 안에 읽으면 되고,
  오래 남기려면 수집 스크립트가 구글 시트로 옮깁니다(`tools/collect.mjs` 설명 참고).
