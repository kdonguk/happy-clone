동욱 님을 위한 **화면 시안 ↔ 서버 흐름도 연결 리뷰 보드**입니다.
화면과 서버가 어떻게 이어지는지 칩으로 바로 확인하고, 의견을 남길 자리를 톡 누른 뒤 한 줄만 적으면 됩니다.

- 구성: `index.html` · `styles.css` · `app.js` (빌드 없음, 의존성 없음)
- 로그인 없음. 아이폰 Safari 와 PC 브라우저에서 바로 열립니다.

  - 주소: **https://kdonguk.github.io/happy-clone/**
  - 바로가기: 흐름도만 보기 `…/happy-clone/#flow`

## 화면 ↔ 서버 연결

화면 시안의 각 카드 아래에 `🔗 서버 흐름: ③ 안전장치 검사` 칩이,
서버 흐름도의 각 단계 안에 `🖥️ 화면: S2 직접 연결` 칩이 붙습니다.

- 화면 칩을 누르면 → 흐름도 탭으로 넘어가 그 단계가 **화면 중앙으로 이동하고 파랗게 강조됩니다**.
- 흐름도 칩을 누르면 → 화면 시안 탭으로 넘어가 그 화면 카드로 이동해 강조됩니다.
- 강조 표시는 **다음에 다른 곳을 고를 때까지 남습니다** — 탭을 오가며 봐도 방금 고른 곳이 보입니다.
- 넓은 화면(1024px 이상)은 상단 **`⇹ 나란히 보기`** 로 왼쪽 화면 시안 · 오른쪽 흐름도를 동시에 띄웁니다.
  이때 한쪽의 칩이나 카드를 누르면 반대쪽 대응 요소가 즉시 강조·스크롤됩니다.
- 좁은 화면(아이폰)은 탭 전환 + 칩 원클릭 점프로 동작합니다.
- `📌 핀 찍기` 모드에서도 연결 칩은 이동으로 동작하고, 핀은 칩이 아닌 자리에만 꽂힙니다.

### 매핑 데이터

매핑의 원본은 `index.html` 마크업입니다. 화면과 흐름이 서로를 가리키는지 앱이 스스로 점검합니다
(브라우저 콘솔에서 `__taBoard.audit()`).

| 화면 | 서버 흐름 단계 |
| --- | --- |
| S1 실행 대상 선택 | ① 요청 접수 · ② 요청 스키마 검증 · ⑤ 실행 분기 (대상 카드: ⑤a 정산 개발 DB 읽기 / ⑤b 배치 실행) |
| S2 직접 연결 · 안전 배지 | ② 요청 스키마 검증 · ③ 안전장치 검사 · ④ 거절·사유 반환 |
| S3 14단계 진행 | ⑤ 실행 분기 · ⑥ 결과 계약 검증 · ⑦ 파일 영속화 |
| S4 검증 결과 요약 | ⑥ 결과 계약 검증(자가 치유 포함) · ⑦ 파일 영속화 · ⑧ 보고·응답 |

- 화면 카드: `data-screen="S1" data-nodes="n1 n2 n5"`
- 화면 안 세부 영역: `data-region="n3 n4"`
- 흐름 노드: `g.node[data-node][data-screens][data-chip]`

## 쓰는 법

1. 위 탭에서 **① 화면 시안** 또는 **② 서버 흐름도**를 고릅니다.
2. `📌 핀 찍기` 로 바꾸고 의견을 남길 자리를 **짧게 탭**합니다.
3. 뜬 시트에 한 줄 적고 **저장** (빠른 문구 버튼을 눌러도 됩니다).
4. 오른쪽 아래 **의견 제출** → 피클에게 전달됩니다.
5. `📌 남긴 의견` 목록에서 행을 누르면 그 핀으로 이동합니다. ✏️ 수정 / 🗑 삭제.
6. 헤더의 리뷰 ID 칩을 누르면 프로젝트·버전 ID를 바꿀 수 있습니다(예: `testanchor-sample-v1`).

흐름도 탭은 `+ / − / ⤢` 버튼, 두 손가락 확대, 끌어서 이동, 휠 이동(`Ctrl/⌘ + 휠` 확대)을 지원합니다.
핀 모드에서도 끌면 화면이 움직이고, 짧게 탭할 때만 핀이 꽂힙니다.
